# Portfolio Professionnel - Brouhanoudine OMOROU

Bienvenue dans le dépôt de mon portfolio professionnel en ligne. Ce site présente mon profil d'étudiant en Génie Logiciel, mes compétences techniques, mes formations, mes certifications ainsi que les projets web que j'ai réalisés.

## 🚀 Fonctionnalités & Sections

Le portfolio est entièrement responsive (adapté aux mobiles, tablettes et ordinateurs) et est structuré de la manière suivante :

- **Écran de Chargement (Preloader)** : Un écran d'accueil personnalisé avec un spinner fluide et un logo pulsant pour une expérience utilisateur premium.
- **Section Héros (Accueil)** : Introduction rapide, photo de profil, et boutons d'appel à l'action pour voir mes projets ou me contacter.
- **À Propos de Moi** : Description de mon profil, de mon parcours à l'École Supérieure des Affaires (ESA) de Lomé, et de mes traits de personnalité.
- **Formations & Matières clés** : Détail de mon parcours académique et des matières étudiées (Algorithmique, Base de données, POO, Agile/Scrum, Git/Github).
- **Compétences** : Barres de progression dynamique affichant ma maîtrise des technologies (PHP, MySQL, HTML/CSS/Tailwind, JavaScript, C, Delphi, etc.).
- **Programmes & Certifications** : Mise en valeur de mes réussites (Miabe Hackathon 2025, Passeport numérique de *10 000 Codeurs*, Challenge Tech Santé 2026).
- **Projets Réalisés** : Cartes interactives présentant mes projets majeurs avec des liens directs vers leurs dépôts GitHub (*Plateforme de bourses et stages*, *MaisonParfaite*).
- **Contact** : Formulaire de contact fonctionnel intégré avec l'API **EmailJS** pour l'envoi direct d'e-mails, ainsi que mes liens de contact (LinkedIn, GitHub, Téléphone et E-mail).

## 🎨 Animations & Expérience Utilisateur

Le site intègre des animations de transition et d'apparition haut de gamme :
- **Préchargeur intelligent** : S'estompe proprement dès que les éléments de la page sont prêts.
- **Scroll Reveal (Apparition au défilement)** : Intégration d'un `IntersectionObserver` en JavaScript qui déclenche les animations (glissements, zooms, cascades) uniquement lorsque les sections entrent dans le champ de vision du navigateur pour la première fois.
- **Déclenchement unique** : Les animations ne se rejouent pas lorsque l'utilisateur remonte la page, ce qui garantit une navigation fluide et naturelle.

## 💻 Installation et Lancement Local

Comme le projet est construit avec des technologies web standards sans compilation complexe, vous pouvez le lancer très facilement.

### Option 1 : Lancement simple (Double-clic)
Vous pouvez ouvrir directement le fichier `index.html` dans n'importe quel navigateur web moderne.

### Option 2 : Lancement avec le serveur intégré PHP (Recommandé)
Si PHP est installé sur votre machine, vous pouvez démarrer un serveur web local dans le répertoire du projet en ouvrant votre terminal et en exécutant :

```bash
php -S localhost:8000
```

Ensuite, ouvrez votre navigateur et accédez à l'adresse suivante :
👉 [http://localhost:8000](http://localhost:8000)
